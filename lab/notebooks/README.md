# Notebook Layout

This folder is reserved for standalone notebooks that may later be mirrored into the book.

Suggested pattern:

- `foundations/`
- `build/`
- `export/`
- `spectral/`
- `diagnostics/`
- `externalities/`
- `interpolation/`
- `simulate/`

For the first scaffold, the rendered book pages themselves are written as MyST notebook pages so we can add runnable cells directly inside the site.
