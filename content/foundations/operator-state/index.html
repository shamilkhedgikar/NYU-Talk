Operator State

The RelWeights operator state is the minimal reusable object that the rest of the lab needs:

B⟶R⟶LRB \longrightarrow R \longrightarrow L_RB⟶R⟶LR​
(1)

Everything downstream in the lab is a reuse of this pipeline, whether the goal is smoothing, diagnostics, spectral decomposition, or operator export.

Note

This page follows Sections 1 through 6 of the reference note and uses the proposal’s notation of an analysis layer α\alphaα and an inherited support layer β\betaβ.

2. RelWeights matrix¶

Once BBB is fixed, relational similarity is induced by shared support:

R=BB⊤−diag⁡(BB⊤)R = B B^{\top} - \operatorname{diag}(B B^{\top})R=BB⊤−diag(BB⊤)
(6)

Entrywise,

Rij=∑kBikBjkR_{ij} = \sum_k B_{ik} B_{jk}Rij​=k∑​Bik​Bjk​
(7)

before diagonal removal. The interpretation is direct: two α\alphaα-units are close in RRR when they inherit the same contextual supports in β\betaβ.

Main properties:

  • Rij≥0R_{ij} \ge 0Rij​≥0

  • RRR is symmetric

  • rank⁡(R)≤rank⁡(B)\operatorname{rank}(R) \le \operatorname{rank}(B)rank(R)≤rank(B)

  • BB⊤B B^{\top}BB⊤ is a valid positive semidefinite Gram matrix

That last point matters because it shows the construction is not ad hoc. It is a kernel induced by the incidence embedding.

3. Laplacian matrix¶

Define the degree matrix from the row sums of RRR:

(8)

Then define the relational Laplacian:

LR=DR−RL_R = D_R - RLR​=DR​−R
(9)

At this point the overlay construction has become an operator. RRR is similarity, while LRL_RLR​ is the discrete curvature or friction operator that will drive most of the analyses in the lab.

4. Quadratic form identity¶

For any x∈Rnx \in \mathbb{R}^nx∈Rn,

x⊤LRx=12∑i,jRij(xi−xj)2x^{\top} L_R x = \frac{1}{2} \sum_{i,j} R_{ij}(x_i - x_j)^2x⊤LR​x=21​i,j∑​Rij​(xi​−xj​)2
(11)

This identity is the most useful interpretive bridge between geometry and analysis. It says that LRL_RLR​ measures relational roughness: variation is penalized when it occurs across units with strong shared support.

That is why the same matrix can serve:

  • regularization in interpolation

  • smoothness diagnostics

  • spectral embeddings

  • diffusion and propagation operators

5. Positive semidefiniteness¶

Because each term (xi−xj)2(x_i - x_j)^2(xi​−xj​)2 is nonnegative and each RijR_{ij}Rij​ is nonnegative,

x⊤LRx≥0x^{\top} L_R x \ge 0x⊤LR​x≥0
(12)

for every xxx. Therefore LRL_RLR​ is positive semidefinite, and its eigenvalues satisfy

λk≥0\lambda_k \ge 0λk​≥0
(13)

This is the structural reason the operator behaves like a graph Laplacian even though the graph is induced by overlays rather than by border adjacency.

6. Nullspace property¶

The constant vector lies in the nullspace:

LR1=0L_R \mathbf{1} = 0LR​1=0
(14)

So constants have zero relational curvature. If the relational graph is connected, the constant mode spans the entire zero eigenspace. If the graph is disconnected, the multiplicity of the zero eigenvalue tracks the number of connected components.

For the lab, the operational interpretation is simple:

  • zero mode: baseline level

  • low-frequency modes: smooth contextual gradients

  • high-frequency modes: sharp disagreement across shared supports

Minimal construction code¶

import numpy as np


def build_relweights(B):
    B = np.asarray(B, dtype=float)
    gram = B @ B.T
    R = gram - np.diag(np.diag(gram))
    D_R = np.diag(R.sum(axis=1))
    L_R = D_R - R
    return {"B": B, "gram": gram, "R": R, "D_R": D_R, "L_R": L_R}


toy = build_relweights(
    [
        [1, 1, 0, 0],
        [1, 1, 1, 0],
        [0, 1, 1, 1],
        [0, 0, 1, 1],
    ]
)

toy["R"], toy["L_R"]
