Construction Roadmap

We start from a broad overlap problem. The proposal frames the method as a way to convert layered spatial intersections into reusable operators, so the same construction can support diagnostics, smoothing, spectral analysis, and policy interpretation. In that framing, the geometry that matters is inherited support in β\betaβ, not only shared boundaries in α\alphaα.

Step 1: Choose the two layers¶

Let α={α1,…,αn}\alpha = \{\alpha_1, \ldots, \alpha_n\}α={α1​,…,αn​} denote the analysis layer and let β={β1,…,βm}\beta = \{\beta_1, \ldots, \beta_m\}β={β1​,…,βm​} denote the contextual or inherited support layer. Typical examples are:

  • districts over hydrological basins

  • tracts over school catchments

  • neighborhoods over policy zones

The key design choice is that β\betaβ defines the support pattern that will later induce similarity among the α\alphaα units.

Step 2: Build the incidence matrix¶

The reference note starts with two versions of the incidence matrix BBB.

Binary support:

Bbin(i,k)={1if ∣αi∩βk∣>00otherwiseB_{\mathrm{bin}}(i,k) = \begin{cases} 1 & \text{if } |\alpha_i \cap \beta_k| > 0 \\ 0 & \text{otherwise} \end{cases}Bbin​(i,k)={10​if ∣αi​∩βk​∣>0otherwise​
(1)

Area-overlap support:

Barea(i,k)=∣αi∩βk∣∣αi∣B_{\mathrm{area}}(i,k) = \frac{|\alpha_i \cap \beta_k|}{|\alpha_i|}Barea​(i,k)=∣αi​∣∣αi​∩βk​∣​
(2)

For the area-based construction, each row is normalized over the support carried by αi\alpha_iαi​:

∑kBarea(i,k)=1\sum_k B_{\mathrm{area}}(i,k) = 1k∑​Barea​(i,k)=1
(3)

The binary matrix is just the support pattern of the area-overlap matrix:

Bbin(i,k)=1 ⁣(Barea(i,k)>0)B_{\mathrm{bin}}(i,k) = \mathbf{1}\!\left(B_{\mathrm{area}}(i,k) > 0\right)Bbin​(i,k)=1(Barea​(i,k)>0)
(4)

This is the point where an overlay becomes algebraic. Once the intersection structure is in BBB, the rest of the operator stack is matrix construction.

Step 3: Form the RelWeights kernel¶

The relational similarity matrix is built from shared support:

R=BB⊤−diag⁡(BB⊤)R = B B^{\top} - \operatorname{diag}(B B^{\top})R=BB⊤−diag(BB⊤)
(5)

Entrywise,

Rij=∑kBikBjkR_{ij} = \sum_k B_{ik} B_{jk}Rij​=k∑​Bik​Bjk​
(6)

before diagonal removal. In words, RijR_{ij}Rij​ measures how much contextual support units αi\alpha_iαi​ and αj\alpha_jαj​ inherit in common through β\betaβ.

The reference note emphasizes the main properties immediately:

  • Rij≥0R_{ij} \ge 0Rij​≥0

  • RRR is symmetric

  • rank⁡(R)≤rank⁡(B)\operatorname{rank}(R) \le \operatorname{rank}(B)rank(R)≤rank(B)

  • BB⊤B B^{\top}BB⊤ is positive semidefinite before the diagonal is removed

Step 4: Lift similarity into a Laplacian¶

Define the relational degree matrix from the row sums of RRR:

(DR)ii=∑jRij(D_R)_{ii} = \sum_j R_{ij}(DR​)ii​=j∑​Rij​
(7)

Then define the relational Laplacian:

LR=DR−RL_R = D_R - RLR​=DR​−R
(8)

Entrywise,

(LR)ij=δij∑kRik−Rij(L_R)_{ij} = \delta_{ij} \sum_k R_{ik} - R_{ij}(LR​)ij​=δij​k∑​Rik​−Rij​
(9)

This is the operator form that the rest of the lab will reuse.

Step 5: Read the quadratic form as roughness¶

For any signal x∈Rnx \in \mathbb{R}^nx∈Rn, the core identity is

x⊤LRx=12∑i,jRij(xi−xj)2x^{\top} L_R x = \frac{1}{2} \sum_{i,j} R_{ij} (x_i - x_j)^2x⊤LR​x=21​i,j∑​Rij​(xi​−xj​)2
(10)

This is the most useful interpretation to keep in mind while building the lab. The quadratic form is an energy functional: it is small when values vary smoothly across units that share inherited support, and large when strongly related units diverge.

Step 6: Use the spectrum¶

Because (xi−xj)2≥0(x_i - x_j)^2 \ge 0(xi​−xj​)2≥0 and Rij≥0R_{ij} \ge 0Rij​≥0, the reference note shows that

x⊤LRx≥0x^{\top} L_R x \ge 0x⊤LR​x≥0
(11)

so LRL_RLR​ is positive semidefinite and all eigenvalues satisfy λ≥0\lambda \ge 0λ≥0. It also shows that the constant vector lies in the nullspace:

LR1=0L_R \mathbf{1} = 0LR​1=0
(12)

That gives the standard spectral picture:

  • the zero mode is constant over connected relational support

  • small eigenvalues correspond to smooth relational variation

  • larger eigenvalues capture oscillatory or high-friction variation

Worked proposal example¶

The proposal gives a compact 4×44 \times 44×4 binary example with districts α={A,B,C,D}\alpha = \{A, B, C, D\}α={A,B,C,D} and contextual regimes β={X,Y,Z,W}\beta = \{X, Y, Z, W\}β={X,Y,Z,W}:

  • AAA intersects X,YX, YX,Y

  • BBB intersects X,Y,ZX, Y, ZX,Y,Z

  • CCC intersects W,Y,ZW, Y, ZW,Y,Z

  • DDD intersects W,ZW, ZW,Z

What this page sets up¶

This six-step construction is the backbone of the rest of the lab:

  • build will construct BBB, RRR, and LRL_RLR​ from real overlays

  • export will move those operators into PySAL and related formats

  • spectral will study the eigenstructure of LRL_RLR​

  • diagnostics and externalities will use the same operator to test and interpret dependence

The companion notebook now turns the same derivation into executable matrix checks.
